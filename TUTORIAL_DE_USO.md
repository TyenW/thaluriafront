# 📖 Guia Ligeiro do Viajante

> *Breve pergaminho para quem chega com pressa. Os saberes completos jazem no [Códice de Thalúria](README.md).*

## Primeiro — Acender o Motor

```powershell
cd c:\Users\Usuário\Desktop\codigos\thaluriaback
.\iniciar_servidor.bat
```

## Segundo — Abrir os Portões

```powershell
cd c:\Users\Usuário\Desktop\codigos\thaluriafront
npm run dev
```

Abra **http://localhost:5173**.

## Terceiro — Entrar

| Título | Usuário | Senha |
| :--- | :--- | :--- |
| Mestre da Mesa | `mestre` | `Senha14933` |
| Aventureiro | `jogador1` | `123456` |

## Quarto — Provar os Poderes

1. Como **Mestre**, em **Gerenciar → Monstros → Novo**, envie uma ilustração e veja o cartão do bestiário ganhar forma.
2. No **Painel**, toque no 🎁 de uma ficha e conceda um item.
3. Como **jogador1**, abra a ficha e encontre o item na aba **Inventário**.
